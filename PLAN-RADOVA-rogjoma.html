Plan radova Rog-Joma × Hajtek

Sve što ide Janu, podjela tko što radi i procjena trajanja. Model: Jan šalje kod (ZIP) i radi kritične zahvate + deploy; naš AI tim (Claude Code, Codex, Gemini) razvija ostalo lokalno kroz git i isporučuje patcheve na Janov pregled.

Jan (Hajtek) Mi — AI tim + Ivo Zajednički

Korak 0 Pristup — preduvjet svega

Jan šalje (jednokratno):

  • Izvorni kod — ZIP aktualne produkcije (ili git pristup). Minimum ako cijeli ZIP ne ide odmah: aj_general.php, artikli_pregled_*.php, size_tab*.php, product_group_banner_small.php, index_page_row_column.php, javni templati (listing, artikl, naslovnica, pretraga), ERP import skripta (pravi naziv + cron), DB konekcija/funkcije.
  • Struktura baze — SQL DDL + anonimizirani dump bez osobnih podataka kupaca (artikli, zalihe po skladištima, grupe/brendovi, atributi, tabovi veličina, banneri s html_field/display_type).
  • Upute za lokalno podizanje — verzija PHP-a, ekstenzije, config bez lozinki.
